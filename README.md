# 🎵 **_Spotify Exploratory Data Analysis (2015–2025)_**

**_This project focuses on performing Exploratory Data Analysis (EDA) on Spotify song data from 2015 to 2025 using Python._**  
**_The aim of this project is to understand trends, patterns, and relationships between song popularity, streaming behavior, genres, and audio features._**

---

## 📊 **_Dataset Overview_**
**_The dataset contains information about Spotify tracks, including:_**
- **_Track and artist details_** 🎤  
- **_Release year_** 📅  
- **_Popularity score_** ⭐  
- **_Stream count_** 📈  
- **_Audio features such as danceability, energy, loudness, tempo, and instrumentalness_** 🎶  

**_Dataset Source:_** **_Publicly available Spotify data_**

---

## 🛠️ **_Tools & Libraries Used_**
- **_Python_** 🐍  
- **_Pandas_**  
- **_NumPy_**  
- **_Matplotlib_**  
- **_Seaborn_**

---

## 🔍 **_Key Analysis Performed_**
- **_Year-wise trend of song releases_**  
- **_Average popularity trends over time_**  
- **_Genre-wise popularity analysis_**  
- **_Popularity distribution across genres_**  
- **_Stream count vs popularity analysis (linear & log scale)_**  
- **_Correlation analysis of audio features_**  
- **_Explicit vs non-explicit song comparison_**  
- **_Artist-level popularity analysis_**  
- **_Popularity band analysis and blockbuster song identification_**

---

## 💡 **_Key Insights_**
- **_Song releases remained relatively consistent from 2015 to 2025._**  
- **_Average song popularity showed minimal variation over time._**  
- **_Stream count has a noticeable positive relationship with popularity._**  
- **_Audio features alone do not strongly influence popularity._**  
- **_Explicit content does not significantly impact a song’s popularity._**
